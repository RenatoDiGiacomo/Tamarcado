Privacidade

Política de Privacidade

Última atualização: 27 de agosto de 2026

1. Quem somos

O Tamarcado é um sistema de agendamento online operado por Renato Di Giacomo, CNPJ 36.054.293/0001-37, com sede no Estado de São Paulo.

Nesta política, "nós" ou "Tamarcado" se refere a essa empresa; "você" se refere a quem usa o sistema.

Contato para assuntos de privacidade: contato@tamarcado.tec.br

2. Duas situações diferentes — leia com atenção

O Tamarcado trata dados pessoais em duas situações distintas, e as responsabilidades são diferentes em cada uma.

2.1 Dados de quem contrata o Tamarcado

Quando um estabelecimento (salão, barbearia, estúdio, profissional autônomo) contrata o Tamarcado, nós somos os controladores dos dados dessa pessoa e respondemos diretamente por eles.

2.2 Dados das clientes do estabelecimento

Quando uma cliente agenda um horário — pelo link público, pelo WhatsApp ou sendo cadastrada pelo próprio estabelecimento —, quem decide coletar esses dados é o estabelecimento, não nós.

Nessa situação:

  • O estabelecimento é o controlador: define o que coleta, para quê, e por quanto tempo mantém.
  • O Tamarcado é o operador: apenas armazena e processa os dados conforme as instruções do estabelecimento, sem usá-los para finalidade própria.

Na prática: se você é cliente de um salão e quer excluir seus dados ou saber o que está guardado, procure o estabelecimento onde você se atende. Ele é quem tem essa relação com você. Se preferir, pode nos escrever, e nós encaminharemos ao estabelecimento responsável.

Coletamos apenas o necessário para o agendamento funcionar. Não pedimos CPF, endereço, dados bancários ou qualquer informação sensível das clientes finais.

3.3 Da navegação no site

Usamos o Google Analytics para entender como as pessoas chegam e navegam no site tamarcado.tec.br. Ele coleta dados de navegação — páginas visitadas, tempo de permanência, origem do acesso, tipo de dispositivo — de forma agregada.

Você pode bloquear essa coleta nas configurações do seu navegador ou por extensões de bloqueio.

4. Por que tratamos esses dados

Tratamos dados pessoais com base nas seguintes hipóteses legais previstas na Lei Geral de Proteção de Dados (Lei 13.709/2018):

  • Execução de contrato — para fornecer o sistema que você contratou.
  • Consentimento — quando a cliente marca a caixa de concordância no agendamento pelo link público.
  • Legítimo interesse — para segurança do sistema, prevenção de fraude e melhoria do serviço, sempre respeitando seus direitos.
  • Cumprimento de obrigação legal — quando alguma lei nos obrigar a manter ou fornecer informação.

Não vendemos dados pessoais. Não usamos os dados das clientes de um estabelecimento para oferecer nada a elas, nem os compartilhamos com outros estabelecimentos.

Também podemos compartilhar dados quando exigido por autoridade competente ou determinação judicial.

6. Por quanto tempo guardamos

Enquanto a conta estiver ativa, mantemos os dados necessários ao funcionamento do sistema.

Após o encerramento, mantemos os dados por até 90 dias, para o caso de você querer reativar a conta ou recuperar informações. Depois desse prazo, os dados são excluídos, exceto o que a lei nos obrigue a manter.

Backups são mantidos por período limitado e sobrescritos automaticamente.

7. Seus direitos

A LGPD garante a você o direito de:

  • Confirmar se tratamos dados seus e acessar esses dados
  • Corrigir dados incompletos, inexatos ou desatualizados
  • Solicitar anonimização, bloqueio ou eliminação de dados desnecessários ou tratados em desconformidade com a lei
  • Solicitar a portabilidade dos dados a outro fornecedor
  • Revogar o consentimento a qualquer momento
  • Ser informado sobre com quem compartilhamos seus dados
  • Opor-se a um tratamento feito com base em legítimo interesse

Para exercer qualquer um deles, escreva para contato@tamarcado.tec.br. Responderemos no prazo previsto em lei.

Se você é cliente de um estabelecimento que usa o Tamarcado, esses direitos devem ser exercidos junto ao estabelecimento, que é o controlador dos seus dados. Podemos encaminhar sua solicitação, mas quem decide é ele.

8. Segurança

Adotamos medidas técnicas e organizacionais para proteger os dados, entre elas:

  • Comunicação criptografada (HTTPS) em todo o sistema
  • Senhas armazenadas com criptografia irreversível — nem nós conseguimos vê-las
  • Isolamento entre estabelecimentos: cada um acessa apenas os próprios dados
  • Controle de acesso por perfil, definido pelo dono de cada estabelecimento
  • Backup diário do banco de dados
  • Servidor com acesso restrito por chave criptográfica

Nenhum sistema é completamente imune. Se ocorrer um incidente de segurança que possa causar risco relevante a você, comunicaremos você e a Autoridade Nacional de Proteção de Dados, conforme a lei exige.

9. Cookies

O site usa cookies para:

  • Funcionamento essencial — manter você conectado ao painel
  • Análise — Google Analytics, conforme o item 3.3

Você pode configurar seu navegador para bloquear cookies, mas isso pode impedir o funcionamento do painel.

10. Crianças e adolescentes

O Tamarcado não é destinado a menores de 18 anos. Se um estabelecimento cadastrar dados de menor de idade, é responsabilidade dele obter o consentimento de pelo menos um dos pais ou do responsável legal, conforme a LGPD.

11. Alterações nesta política

Podemos atualizar esta política. Quando a mudança for relevante, avisaremos por e-mail ou por aviso no sistema. A data da última atualização está no topo.
