# Decision Log — Tamarcado Product Brief

## Sessão: 2026-06-15

### Decisões confirmadas pelo usuário

**D-001 — Canal do cliente: WhatsApp exclusivo**
Cliente usa SOMENTE o WhatsApp. Nenhuma interface web ou app para o cliente final.
Razão: comportamento já existente no mercado; elimina fricção de adoção.

**D-002 — MVP sem pagamento no WhatsApp**
Pagamento dentro do fluxo WhatsApp (PIX/sinal) é feature futura. No MVP, registro de pagamento é manual no painel web.

**D-003 — MVP sem IA**
IA no WhatsApp e no painel é feature futura. Bot do MVP é baseado em fluxo estruturado/menus.

**D-004 — Multi-profissional incluído no MVP**
Salões com múltiplos profissionais são suportados desde o MVP, com níveis de permissão (dono/profissional/funcionário) e agendas independentes.

**D-005 — Recusa obrigatória com justificativa**
Profissional não pode recusar agendamento sem informar motivo. Bot reabre fluxo ao cliente após recusa.

**D-006 — Personalização por instalação, não editor aberto**
Customização (nome, logo, cores) feita na instalação pelo dev, não pelo cliente via interface.

**D-007 — Modelo de negócio: mensalidade + setup fee**
R$59–99/mês por profissional + fee de projeto (40% início / 60% entrega). Sem comissão em PIX no MVP.

**D-008 — Go-to-market: venda consultiva direta**
Não há marketing digital no lançamento. Cada cliente é uma venda consultiva (door-to-door).
Razão: validar produto-mercado antes de escalar.

**D-009 — Stack técnica definida**
NestJS + MySQL (backend), ReactTS (web), React Native + Expo (mobile), Evolution API (WhatsApp), Asaas (pagamentos). Não aberta a revisão no brief.

### Suposições — Resolvidas em 2026-06-15

**S-001 — Meta inicial: 5 profissionais pagantes em 90 dias** ✓ CONFIRMADO
Validado pelo usuário. Realista para venda door-to-door solo.

**S-002 — Meta de 6 meses: 25–50 profissionais** ✓ CONFIRMADO (MRR revisado)
Meta de profissionais confirmada. MRR ajustado para R$2.500–7.500 com base no novo pricing por tiers.

**S-003 — Sem trial gratuito** ✓ CONFIRMADO
Setup fee (R$1.500–3.000) filtra cliente sério. Sem trial.

**S-004 — Tiers de pricing** ✓ DEFINIDO
- Autônomo Solo: setup R$1.500–2.000 + R$99–149/mês
- Salão Multi-profissional: setup R$3.000 + R$249–300/mês
Lógica: valor escala por número de profissionais e nível de done-for-you.
Nota: mensalidade já dimensionada para absorver custo de IA futura com teto generoso.

**S-005 — Timeout de confirmação** ✓ DEFINIDO
2 horas em horário comercial. Se exceder: bot avisa cliente ("em análise, retorno em breve"). Sem cancelamento automático no MVP — isso é refinamento futuro.
